# Parametrické programování a intervalové metody
Parametrická skalarizace ve vícekriteriální optimalizaci a vztah s eficientními řešeními, speciální výsledky pro konvexní a lineární úlohy. Intervalová soustava lineárních rovnic a nerovnic, různé typy řešení. Vlastnosti intervalových matic - regularita, vlastní čísla. Deterministická globální optimalizace, horní a dolní odhady na účelovou funkci a optimální hodnotu.

- Vícekriteriální optimalizace
- Intervalové metody
